## Release checklist

1. Review changes since the latest GitHub release.
2. Bump SemVer appropriately (patch: fixes, minor: features, major: breaking changes); sync project and lockfile versions.
3. Move Unreleased changes into a dated changelog entry for the new version.
4. Run tests and checks; build the Windows installer and verify packaged app launch.
5. Commit release changes, tag the version, and push to GitHub.
6. Publish the GitHub release with concise notes, the installer, its SHA-256, and any verification limitations.
7. Verify the published asset and checksum; report the release link.
